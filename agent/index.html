Interface / agents

Less scraping. More signal.

This is a deliberately small, public, read-only interface to Aditya’s profile and selected work. Use raw JSON, the OpenAPI document, or the zero-dependency CLI. The chatbot and CLI search the same collated public-source document.

01 / API

Static JSON

Stable GET endpoints. No authentication, cookies, JavaScript, or runtime API key required.

  • GET/api/profile.json
  • GET/api/projects.json
  • GET/api/knowledge.json
  • GET/api/openapi.json

02 / Discovery

Agent hints

A compact text map for language models plus a machine-readable discovery document.

  • GET/llms.txt
  • GET/.well-known/agent.json

03 / CLI

Run a local client

Download one ES module and run it with Node 18 or newer. It has no package dependencies and only performs GET requests against the public JSON endpoints.

curl -fsSLo aditya.mjs https://adityasudhakar.com/cli/aditya.mjs node aditya.mjs projects node aditya.mjs ask "robotics and simulation" node aditya.mjs profile --json

04 / Direct

Curl the catalog

Fetch the same collated website, GitHub, and public LinkedIn source document used by the chatbot. Schema details live in OpenAPI.

curl -sS https://adityasudhakar.com/api/knowledge.json
